Renewed products need separate guardrails

Scope and definitions

The dashboard uses the repository file apple_products_pricing_2020_2026.csv: 80,000 marketplace listing observations from 2020–2026. “Regular days” corresponds to the dataset value None in Sale_Event. Prices are shown in USD.

  • Average discount: mean of Discount_Pct.
  • Available stock: listings with Stock_Status = In Stock divided by all listings.
  • Markup case: listing with negative discount, meaning current price exceeds launch price.
  • Reviews: engagement proxy, not units sold.

Responsible interpretation

The dataset does not contain costs, margins, actual sales, customer identities or competitor prices. Therefore, the analysis cannot calculate real revenue or profit and cannot establish that a promotion caused demand. Model output should support human review, with error monitoring by platform, category, condition, event and stock status.

Dataset license must be confirmed on the original Kaggle page before publishing or redistributing the CSV. The HTML contains only aggregated results.
